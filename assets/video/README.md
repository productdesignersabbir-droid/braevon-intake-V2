# Hero video

Screen 1 plays `hero.mp4` from this folder, muted and looping, in a 432x241
(16:9-ish) frame with a 16px radius.

**The file is not here yet.** Until it is, the `poster`
(`assets/images/stat-hero.jpg`) fills the frame, so the screen renders correctly
— it just does not move. Drop the clip in as `hero.mp4` and it plays with no
other change.

The reference's own clip is MEDVi's footage, with their actors and their
product in shot, so it is not reused here — the same call v1 made about
DirectMeds' photography.

Encode to roughly 432x241 at 2x (about 864x482), H.264, no audio track, a few
seconds long, under ~2MB.
